Changing the key:
  1. Generate the SHA-256 hash of the new key.
  2. Open academy.js.
  3. Replace the PASS_HASH value near the top of the file.
  4. The plain-text fallback at the end of the digest function is used only in
     old/non-secure browser contexts. Replace ARSALAN2026 there as well.

ACADEMY OS PHASE 1
  Mission Control is now the default workspace.
  Multiple academies reference one canonical Knowledge Library.
  Missions follow Learn → Practice → Solve → Verify.
  Competency and readiness increase only after all mission steps and written
  evidence are completed.
  The structured Content Editor creates local topic, course lesson and mission records with
  validation, learner preview, draft/published status and browser persistence.
  Backups use the versioned academy-os-backup envelope and SHA-256 checksum.

PHASE 1 DATA NOTE
  Academy OS is intentionally offline first. Progress, mission evidence,
  authored records, notes and settings are stored on this device. Export a
  backup regularly and before clearing browser data or moving devices.

PHASE 1.1 CONTENT AND EDITOR COMPLETION
  IT Support Academy now contains six goal-based missions, twelve canonical
  Knowledge Library topics and seven practical labs with verification rules.
  Topic records are reused by mission ID rather than duplicated.

  Content Editor actions:
    + NEW TOPIC       Create a local Knowledge Library record.
    + NEW COURSE LESSON
                      Create lesson content, assign it to an academy and link
                      canonical Knowledge Library topics.
    + NEW MISSION     Create a mission and link canonical topics.
    EDIT              Select any record in the Records panel.
    DUPLICATE         Create an editable draft copy.
    DELETE            Remove a record after confirmation.
    SAVE RECORD       Validate and save the current record.
    PUBLISH           Choose Published status and satisfy all validation rules.

  Published local topics appear in the Knowledge Library. Published local
  course lessons appear in their assigned academy, Lessons and Roadmap.
  Published local missions appear in Missions and participate in
  competency/readiness totals.
